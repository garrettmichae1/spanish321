# Implementation and release checks

All 60 units are authored and usable. This checklist separates implemented learning features from independent validation and public distribution.

## Implemented

- [x] Five courses, 12 units each, stable prerequisites, original lectures, readings, worked examples, flashcards, quizzes, homework, communication tasks and remediation.
- [x] Entry checks, cumulative midterms/finals and speaking/writing capstone tasks in all five courses.
- [x] Region-aware teaching, gradual Spanish instructions, transparent human evaluation rubrics, real interaction tasks and explicitly limited solo alternatives.
- [x] Full offline learning loop, local persistence, portfolio, recordings/logs, search, printable guides, CSV import/export and backup/restore.
- [x] Documented and tested scheduling, grading, deep JSON Schema validation, versioned SQLite migration and preservation through content updates.
- [x] Browser E2E for beginner and advanced courses, offline operation, reopening, valid/invalid restore, CSV, simulated microphone, multi-pair matching, search and exports.
- [x] Automated accessibility checks on nine core screens, scalable text and mobile navigation.
- [x] Resource retrieval evidence with uncertain playback/captions explicitly flagged and original offline alternatives.
- [x] Native Linux installer build, with installed-package verification recorded in the content-review report.
- [x] macOS/Windows packaging, native microphone purpose declarations, and successful three-platform CI builds; no public release action.

## Independent validation and public distribution

- [ ] Qualified Spanish-educator review of linguistic accuracy, workload, instructional depth, regional variants and performance rubrics.
- [ ] Observed student usability sessions and manual screen-reader testing.
- [ ] Physical microphone and speaker checks across supported operating systems.
- [ ] macOS/Windows install, OS permission, upgrade/uninstall and native accessibility checks.
- [ ] Creator-media playback/caption review for each selected assignment; changing feeds remain selection tasks with recorded criteria.
- [ ] Independently authored alternate assessment forms. Current cumulative exams transparently reuse the published item bank.
- [ ] Owner confirmation of separate content licensing and authorization for a public binary release; final dependency notices and signing/notarization before that release.

No completion or quiz score is an official CEFR level, college credit, accreditation, or guarantee of fluency. A source push or installer artifact is not a claim of professional educational validation.
