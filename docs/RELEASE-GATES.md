## Release policy

Do not label this complete, CEFR-certified, college credit-bearing, professionally validated, or guaranteed to produce fluency on a schedule. No public binary release has been authorized in this work; the user explicitly authorized pushing source to the existing main branch. Keep preview labeling even if a native package builds. Proposed content licensing must be confirmed before a public release. Third-party resources retain their terms.
