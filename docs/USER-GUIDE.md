# Using Spanish321

## Installation status

There is no signed, student-ready application release. A local Debian 13 x86_64 preview package was built, installed and smoke-tested offline. If you receive that package, verify SHA256SUMS, install with `sudo apt install ./Spanish321_0.2.0_amd64.deb`, and launch Spanish321 from your applications menu. Package dependencies may require internet during installation; study content then works locally. Developers can compile from source; that is different from installing a tested end-user release. Any locally prepared native package is a preview and its verification scope is in the content-review report. macOS and Windows installers have CI build configurations; installation and OS integration require separate testing.

## Your first session

1. Open Today, then Start learning. Read the objectives, explanations and original dialogue.
2. Try the worked examples before revealing their reasoning. Optional outside resources open in your normal browser and require internet.
3. Mark the lesson read and record the self-assessment checks. Both persist locally; reading completion and self-report are not mastery.
4. Take a practice quiz; read explanations. Save assessment attempts separately when working independently without notes.
5. Open Assignments and write your work. Autosave indicates when the local write has completed. Mark who evaluated it; selecting instructor does not arrange an instructor.
6. Review flashcards. Attempt recall before Reveal. Again/Hard/Good/Easy adjusts the due date.
7. Use Practice studio to record or log your practice. Invite a willing real partner when possible. Solo rehearsal does not establish interaction ability.
8. Export a backup from Settings. Browser storage is tied to that browser/origin and can be cleared by the browser; desktop storage is in application data.

## Offline and privacy

Original lessons, quizzes, homework, scheduling and stored recordings are local. A browser preview must finish its first cache installation while online before an offline reload; desktop content is packaged. External media is not bundled. A local Spanish device voice, if present, is synthetic audio. No local voice means listening needs a speaker or external resource; reading alone is not logged as listening.

No account, subscription, telemetry or default upload is used. Microphone permission is requested on recording. Recordings stop after three minutes. Export is deliberate. Backups contain learner work and recordings: store them appropriately.

## Backup, print and export

Settings → Download backup exports versioned JSON. Restore validates, asks before replacing data, then restores it. Export a current copy first. Flashcard CSV exports all cards or an individual unit. For new imports, assign unique IDs such as custom-travel-001; kinds are recognition or production. The header is `id,unit,kind,front,back,example`.

Lesson → Export printable guide saves a complete standalone HTML guide. Open it in a browser and print or save as PDF. Desktop exports use the native Save dialog. Developer-generated guides in release/guides include all answer keys and rubric text in HTML and Markdown. HTML can be printed to PDF without changing the source content.

## Limits

All five courses contain authored materials; none has undergone qualified Spanish-educator validation. No quiz percentage is an official proficiency level. Speech and writing evaluation remain human tasks; automatic grading checks only authored accepted answers.

## Moving through the full curriculum

Courses has five tabs and a search field that searches the selected course’s bundled text. Prerequisites recommend a sequence without locking out experienced learners. Each course has an entry check, cumulative midterm and final. Submit capstone writing and evaluator notes in that unit’s Assignments workspace, and keep speaking evidence in Practice studio. The portfolio keeps reading completion, review activity, assessments and human-evaluated work separate.

Flashcards starts with My current learning. Select a course, unit or difficult-card filter when needed. Your previous reviews remain due even when you move to a later course. Stable IDs preserve work through course updates; old backup format version 1 remains supported by the version 2 database migration.
